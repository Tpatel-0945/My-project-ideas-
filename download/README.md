# AURA as a single file

`AURA.html` is the whole app in one file. Download it, then double-click it to open in Chrome (or drag it into a Chrome window).
Put it on your desktop and it works like an app icon. Your data is saved in Chrome on that computer.

Limits compared with the hosted site (see DEPLOY.md): it can't be installed as an app with its own window, account sign-in/sync is off,
and face scans use the simpler colour analysis because the 3D face model can't load from a file.
Rebuilt from the source with the scratch build script whenever the app changes.
